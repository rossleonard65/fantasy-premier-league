#### Fantasy Premier League Data Analysis

This is a personal data science project relating to Fantasy Premier League (FPL). FPL is a game where football fans pick a squad of players from the Premier League and score points based on how their chosen players perform in real life. Like many things nowadays, this game is heavily data driven, and with the open-source API, analysis and modelling can be conducted to produce data-driven decisions, and give you the upper hand against your friends!
